# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability within this project, please send an email to [arunneupane0000@gmail.com](mailto:arunneupane0000@gmail.com). All security vulnerabilities will be promptly addressed.

Please do NOT report security vulnerabilities through public GitHub issues.

## Supported Versions

| Version | Supported |
|---------|-----------|
| 1.x     | Yes       |

## Security Practices

- No secrets or API keys are committed to the repository
- Environment variables are used for sensitive configuration
- All external links use `rel="noopener noreferrer"`
- Input sanitization is applied where applicable
- HTTPS is enforced in production
